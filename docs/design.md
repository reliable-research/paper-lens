# Paper Lens

Build a Manifest V3 Chrome extension implementing the workflow already described and requested: read an entire PDF, identify core passages across sections, highlight them on original pages, and attach explanations. Use a packaged PDF.js reader because Chrome's native viewer cannot host our annotation UI. Open current PDF through the toolbar, load a local file, paste an HTTPS URL, or use the Monitoring Monitorability test paper downloaded from arXiv.

All text extraction and rule-based ranking run locally. Offer a clearly labeled, source-checked guide for the demo paper. A configurable OpenAI-compatible endpoint can perform whole-paper semantic selection and explanations; no credentials are supplied or inferred. Send document text only after the user explicitly selects AI analysis, with a visible disclosure. Require exact source quotes and validate every returned quote before drawing it. Never pretend local ranking is AI understanding. Preserve notes/annotations per PDF fingerprint, support navigation/search/filtering, and export annotations as JSON/Markdown. No account, backend, or store publication needed.

Default UI: dark ink navigation, warm paper canvas, left argument map, right explanation panel, compact category colors, keyboard-accessible highlight controls. Render pages lazily while parsing all pages. Handle wrapped sentences and PDF ligatures through a text-to-source map; do not match arbitrary fuzzy substrings. Bundled guide must anchor every quote, cover important sections, and include RL/obfuscation qualifications. Scans without a text layer get an explicit OCR-required message.
